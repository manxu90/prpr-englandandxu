This do-file replicates the analysis presented in the paper: “US Women’s First Family-Forming Transitions to Cohabitation or Birth: Differences by Racial and Socioeconomic Disadvantage Challenge the Theory of the Second Demographic Transition.”

To run the analysis, you will need to download the relevant variables from the NLSY website.
The official link to access the variables is: https://www.nlsinfo.org/investigator/pages/home
